# DataPrep

FragonStudios DataPrep is a project for preparing data through a web interface and background processing. This repository will contain the core package, API, worker, UI, and public website.

## Public website

The [DataPrep website](https://fragonstudios.github.io/DataPrep/) will provide project information and documentation. Its source will live in [`website/`](website/).

## Interactive demo

The [interactive demo](https://fragonstudios.github.io/DataPrep/demo/) will let visitors try the DataPrep interface. The UI source will live in [`packages/ui/`](packages/ui/).

## Self-hosted release

The [releases page](https://github.com/FragonStudios/DataPrep/releases) will provide Docker release information for self-hosted deployments.
